# Visual specification

Reference: https://typing-animation.com/, inspected live 2026-10-30.
The supplied reference is the visual baseline, not a separately approved generated concept.
Image Gen is unavailable in this session; no raster concept was fabricated.

- Background #0b0b0d, surface #131315, elevated #1b1b1f, text #f5f5f7,
  secondary #a2a2ad, accent #c8b7f5, border #29292e.
- Self-hosted Inter for body/UI and DM Sans for display, from user's existing
  Typeflow open-source font assets. Preserve their font license files.
- Floating capsule header, 1120px max width, 24px top margin. Brand at left,
  How it works / Image sizes / FAQ at right. No account or payment gate.
- Centered hero, 64px desktop display / 40px mobile, restrained gray description.
- One working input panel, white primary action, purple selected controls.
  Below it a product preview with a real, locally saved sample avatar clearly
  labeled Example. Sample is not presented as a user's completed lookup.
- Result: channel identity, square/circle preview toggle, selected dimensions,
  download action and original-image fallback; all nine sizes visible in
  a compact selector. Do not tile nine identical giant avatars.
- Downstream: three open numbered steps, two-column feature list, compact
  size reference table, use cases, accessible FAQ disclosures, quiet footer.
- No glows, rainbow gradients, stock art, pricing cards, fake metrics, signup.
- Mobile: wrapped minimal nav, stacked form/result, touch targets >=44px,
  no horizontal overflow. Reduced-motion preference honored.
- SVG icons: 24x24, currentColor, 1.7px rounded strokes. Original crop-corner
  avatar brand mark; not YouTube's official logo.

Allowed first-view copy: YT PFP; How it works; Image sizes; FAQ;
YT PFP Downloader; A better look at any YouTube profile.; description of
channel/handle/video input; input label; Get profile picture; Try @YouTube;
Free to use; No sign-up; 9 image sizes; Example preview; Square; Circle;

Enter a channel above to download its profile picture.

Scope: reproduce the linked profile downloader's capabilities, not the entire
ytultra suite. Copy is original English and resolution descriptions distinguish
image dimensions from native source detail.
