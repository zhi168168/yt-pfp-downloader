# YT PFP Downloader SEO 逐项审查与优化

审查日期：2026-11-02（中国时间）。核心词：`yt pfp downloader`。规范首页：`https://www.ytpfp.com/`。

本报告逐节对应桌面的《SEO优化知识文档.md》和《on-page-seo-summary.md》，并逐条核对后者的发布清单。原始知识文档作为审查材料保留；其中购买外链、发布社区帖子、安装统计、扩展页面等建议不自动视为实际操作授权。本次已修改项目代码并验证本地正式构建，尚未推送或部署；下面“已优化”均指本地实现。

## 2. 核心词、意图与页面分工

`yt pfp downloader` 的主要意图是在线找到并保存 YouTube 频道头像。首页保留工具第一、说明第二。核心词由首页承接，不另建 `/yt-pfp-downloader` 重复页。大小写是品牌呈现，不需要为了小写检索词改变所有文字。

| 词簇/需求 | 承接位置 | 决策 |
|---|---|---|
| yt pfp downloader / youtube profile picture downloader | 首页 Title、H1、导语、FAQ | 同一主要搜索意图，合并覆盖 |
| youtube avatar downloader / youtube dp downloader | 功能说明、FAQ 定义 | 自然同义表达，不复制工具页 |
| download youtube profile picture from video link | 首页步骤、链接 FAQ | 已有真实功能，用正文覆盖 |
| youtube profile picture downloader hd / 800px / 1280px | 尺寸表、HD FAQ | 说明实际返回尺寸与放大的区别 |
| save youtube profile picture on iphone / android | 手机保存 FAQ | 先由首页回答，不先生产薄教程 |
| youtube profile picture downloader 4k / original | HD FAQ | 明确不保证原始上传文件、4K 或额外原生细节 |
| youtube profile picture downloader no sign up | 不作为产品承诺 | 当前产品必须登录，不能为流量虚报免注册 |
| old/private youtube profile picture | 历史/隐私 FAQ | 明确当前公开头像的功能边界 |
| youtube banner / thumbnail / community post downloader | 本次不覆盖 | 当前不是这些工具；相关搜索不代表应该堆进首页 |

### 原文中需要单独纠正的经验结论

- 不采用关键词密度 3%–5% 作为优化目标；自然出现即可，本次不通过重复品牌堆密度。
- 不采用信息页必须 800 英文单词或图片一律至少 300×300 的门槛；logo、favicon、教程图、工具预览各有实际尺寸用途。
- “内容完整、外链、用户行为三引擎”可帮助思考，但不是可观测的 Google 评分公式。不要由低曝光倒推出被惩罚。
- 付费曝光不等于可购买的 SEO 权重。产品并非 AI 工具，不因原文推荐 AI 目录就强行按 AI 产品投稿。
- 单周 CTR 变化不一定来自改标题：需同查询、同设备、同国家与相近位置，并关注样本量及季节性；低于 2% 不是跨所有排名的统一异常值。
- 不为“AI 幻觉 URL”统一重定向到首页；真实不存在且没有对应内容时保留 404，只对确认等价的旧地址作 301。
- 类名含 AI 字样本身并不是已确认的搜索惩罚项。本次没有删除正常构建标记、React 标记或必要注释来追求所谓去 AI 化。
